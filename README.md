# DocAgent: демо

Демо проекта DocAgent для конкурса «AI autumn» (направление «ИИ-агенты и автоматизация»).
DocAgent принимает заявление студента, определяет тип, извлекает поля, проверяет полноту,
записывает в журнал и готовит проект ответа. Сомнительные заявления уходят сотруднику на проверку,
а ответ студенту отправляется только после подтверждения сотрудником.

## Что это

Одна HTML-страница без сборки и зависимостей (HTML, CSS, JavaScript).
На странице два экрана: студент подаёт заявление и получает письмо, сотрудник («штаб»)
проверяет и подтверждает ответ. Вкладка «Рядом» показывает оба экрана вместе.

## Как открыть

Откройте `index.html` в браузере. Четыре готовых примера работают сразу.

## Что настоящее, а что имитация

- Четыре готовых заявления: значения полей заданы заранее, это имитация.
- Режим «Своё заявление» читает текст или фото языковой моделью. Он использует возможность
  `claude.use("sample")` платформы claude.ai и работает только при открытии страницы внутри claude.ai
  (с разрешением на запрос к Claude). При обычном открытии файла или на GitHub Pages ИИ-режим
  отключается, а примеры продолжают работать.
- Оба экрана работают в одном окне браузера, это не два разных устройства.
- Письмо студенту не уходит по настоящей почте, оно показано на экране студента.
- Уверенность в полях оценивает сама модель, это не измеренная точность.
- Все данные в демо вымышленные.

## Проверка логики


Тест запускает код страницы с заглушками браузера и модели (Node.js, без пакетов).
