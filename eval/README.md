# Замер точности

Набор вымышленных размеченных заявлений: файлы `01.txt` … `30.rtf` и правильные ответы в `labels.json`.

```
.venv/bin/python eval/make_eval_set.py      # пересоздать набор
.venv/bin/python -m app evaluate --rules    # без ИИ, бесплатно
.venv/bin/python -m app evaluate            # с ИИ: по одному запросу к API на файл
```

Скрипт печатает точность по типу документа, по каждому полю и по маршруту (нужна ли проверка сотрудником),
а также среднее время на документ. Отчёт сохраняется в `eval/report-*.json`.

Набор синтетический и довольно чистый. Для честной оценки добавьте сюда настоящие обезличенные заявления
(фото, сканы, PDF) и разметку к ним в `labels.json`, в том же формате.
